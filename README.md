# MySite - Multi-Page Website

A modern, responsive multi-page website built with HTML, CSS, and vanilla JavaScript.

## Pages

- **Home** (`index.html`) - Hero section, features, stats counter, testimonials, and CTA
- **About** (`about.html`) - Company story, values, and team members
- **Services** (`services.html`) - Detailed service descriptions and pricing plans
- **Gallery** (`gallery.html`) - Filterable project showcase with category filters
- **Contact** (`contact.html`) - Contact form with info panel and FAQ accordion

## Features

- Fully responsive (mobile, tablet, desktop)
- Sticky navigation with mobile hamburger menu
- Animated stat counters (intersection observer)
- Gallery with category filtering
- FAQ accordion
- Scroll reveal animations
- Clean, modern design with CSS custom properties

## How to Use

Open any `.html` file in your browser. No build tools or dependencies required.
